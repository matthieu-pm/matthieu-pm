# Design guidelines

## Typography

- Use sentence case for headings, labels, buttons, badges, navigation, metadata, and interactive examples.
- Never use full uppercase as a visual style. Do not use CSS capitalization to force text into uppercase.
- Keep conventional acronyms and initialisms uppercase when that is their correct spelling, such as UI, UX, AI, CTA, SEO, API, A/B, and 404.
- Create hierarchy with font weight, spacing, color, and borders—not capitalization or excessive letter spacing.
